# Fixes

Per-fix documentation. Each bug fix worth recording gets one self-contained file here, numbered sequentially.

## Convention

- **Filename:** `fix-NNN-short-slug.md` (zero-padded 3-digit id, e.g. `fix-001-team-row-invalid-date.md`).
- **One file per fix.** Cover: symptom (what was wrong, how it showed up), root cause, the change, and how it was verified.
- **Numbers are permanent.** Once assigned, a fix id never changes or gets reused.
- For new capabilities, use `docs/features/` instead.
